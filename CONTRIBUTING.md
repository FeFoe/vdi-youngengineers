# Mitmachen

Danke, dass Du die Seite verbessern willst! Wie Du sie lokal startest, steht in der [README](README.md#lokal-starten).

## Ablauf

1. Eigenen Branch von `main` anlegen.
2. Änderung lokal mit `hugo server` prüfen – am Rechner **und** in Handybreite (rund 390 px).
3. Pull Request gegen `main` öffnen. Die CI „Prüfen“ muss grün sein.

## Screenshots im Pull Request

Jeder Pull Request, der etwas Sichtbares ändert (Layout, Texte, Farben, Karte, Termine, Linkseite …), braucht Screenshots **vorher und nachher**:

- dieselbe Stelle, gleicher Ausschnitt, gleiche Fensterbreite
- Handy (rund 390 px breit) und – falls betroffen – Desktop
- bei Interaktionen (Wischen, Zoomen, Dialoge) gern ein kurzes Video oder GIF

So lässt sich die Änderung ohne lokalen Build beurteilen. Reine Code-, Skript- oder Doku-Änderungen ohne sichtbare Auswirkung brauchen keine Screenshots; dann bitte kurz „keine sichtbare Änderung“ vermerken.

## Grundsätze

Bitte die [Grundsätze aus der README](README.md#grundsätze) einhalten: datensparsam, barrierearm, VDI-CI, einfach zu pflegen. Texte nach DIN 5008, SI-Einheiten ohne Scheingenauigkeit.
